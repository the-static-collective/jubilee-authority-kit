# what-is-the-static-collective-

This document is intentionally unfinished.

It grows only when the Collective actually discovers another answer to what it is. Do not pre-fill it with principles we have not earned in practice.

## bug → feature

When reality refuses the intended path, first ask whether the failure contains information.

Preserve the truth of the failure; do not disguise it as success. Do not force uncertain evidence into the shape the system originally expected.

Then ask whether the residue can become material for something the system could not have done otherwise.

A bug does not become a feature merely because we rename it. The failure remains legible as failure. The feature begins only when that truthful residue is given a new, explicit role.

### Founding specimen: Lyric Compost

Haunted Toaster issue #50 supplied the first clean specimen.

The machine could not reliably locate some lyric lines in time. The wrong response would be to guess timestamps, silently approximate them, or pretend the alignment succeeded.

Instead:

> we couldn't reliably locate these words
>
> therefore they are no longer located things

Aligned lyrics remain authoritative timed cues. Unresolved lyrics remain unresolved evidence. If the user chooses not to repair them, they may be composted into deterministic visual ghosts or material influence without ever becoming subtitle truth.

The failure is preserved. The residue becomes a capability the system could not have produced if it had lied about certainty.

That is `bug → feature`.
